# Mental Workout

- A web application that allows users to practice their multiplication skills.
- I decided to build Mental Workout after finding writing multiplication problems/grading them by hand was too slow, the time saved allowed me to roughly solve 2x more problems in the same time span.

## Features:

- Sound effects that play upon correct/incorrect answer.
- Implemented accessible sound design by adding a volume slider to control the volume which plays a sound after it's changed so the user can gauge the volume.
- A pause menu while in session if the user needs to step away which can be exited via a resume button or pressing escape.
- Each problem generated is unique (neither operand will be the same as the last problem.)
